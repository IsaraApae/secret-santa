# Security

Secret Santa keeps one thing secret: who drew whom. If you find a way to learn that, to open someone
else's page, or to reach anything on the server that a visitor shouldn't, please report it privately
before telling anyone else.

## Reporting

Use **Report a vulnerability** on this repository's
[Security tab](https://github.com/IsaraApae/secret-santa/security/advisories/new). It opens a private
report that only the maintainer can read. Please don't open a public issue for it.

Say what you did, what you saw, and how to see it again.

## What's covered

The code in this repository and the site at https://secretsanta-draw.vercel.app. The README's
[How the secret is kept](README.md#how-the-secret-is-kept) section says what the site promises, and
what it knowingly can't prevent.
